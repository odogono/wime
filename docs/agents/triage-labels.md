# Triage labels

Map each canonical role to the identical GitHub label:

- `needs-triage`: maintainer evaluation required.
- `needs-info`: waiting for reporter information.
- `ready-for-agent`: fully specified and ready for autonomous implementation.
- `ready-for-human`: requires human implementation.
- `wontfix`: will not be actioned.

When a skill names a triage role, apply its mapped label.
Edit this mapping if the repository's label vocabulary changes.
