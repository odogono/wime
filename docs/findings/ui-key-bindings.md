**Every icon has a keyboard shortcut, and a few extra keys pause, quit and toggle sound.**

| Key   | Icon             | Action                              |
| ----- | ---------------- | ----------------------------------- |
| A     | Scroll           | Archive (save or restore)           |
| G     | Arrow            | Give a movement Order ("go to")     |
| M     | Magnifying glass | Down a Level                        |
| O     | Provisions       | Objects: put down, take or use      |
| S     | Eye              | Status                              |
| T     | Hourglass        | Game Speed                          |
| U     | Map              | Up a Level                          |
| N / Y | Window option    | No (continue on) / Yes (accept)     |
| P     | none             | Pause                               |
| X     | none             | Quit, after asking for confirmation |
| Q     | none             | Quiet: sound on or off              |
