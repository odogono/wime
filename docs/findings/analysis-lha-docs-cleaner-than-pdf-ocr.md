**The typed-in `Docs` file in the LHA archive is a much cleaner text of the manual than the PDF's OCR layer, but it stops before the A–Z glossary.**
The PDF is a scan of two-page spreads, and its OCR text is noisy: words run together, letters are misread, and on some glossary pages the scan is too poor to tell, for example, which border of the Shire a Place is on. The `Docs` member reads cleanly up to the end of the strategy section. For the glossary (pdf-p14 to pdf-p23) the PDF is the only source, so facts taken from it deserve a careful second reading of the page image.
