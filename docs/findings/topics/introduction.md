# Introduction

War in Middle Earth was published by Melbourne House in 1988. This document records how it worked, as recovered from the Amiga v1.0 release (the Reference Build), its instruction manual and play. Each statement carries a footnote with its sources and how certain it is: `documented` facts come from the manual, `observed` ones from play, `confirmed` ones from the game's code or data, and `provisional` ones are inferences still waiting for evidence.
