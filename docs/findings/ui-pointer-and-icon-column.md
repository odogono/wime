**The pointer is a blue gauntlet, and the icons sit in a column at the top right; each icon either opens an option window or turns the pointer into the icon's shape for placing on the map.**
When a decision window opens, for example because two Characters meet, any half-finished action the player was in the middle of is cancelled.
