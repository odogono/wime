# Forces Reference runs

The `observed:forces-…` sources in the Findings are these Reference runs, made in FS-UAE 3.2 on the Reference Build (issue #68), with the harness of [the War Event reference](war-events-reference.md#setting-up). Each starts from the starting roster, a little after the start, with the clock set to day 1, quarter-hour 70. One Leader is put one pixel short of another's tile origin, facing it, with that tile origin as its destination. The other Leader is awake, with no destination.

A breakpoint where the window opens stops the emulator with it on screen: code+0x0fdda (0x2CEA2) after the "Follow" or "talk" windows, and code+0x0fea8 (0x2CF70) after the plain one. To answer a window, write the button's id to `defaultButton`, data+0x5553 (0x3E63B), and let the window time out. The timeout dispatches the default the same way a click does (code+0x05b54). Writing `lastButton` directly has no effect. Button ids: 0xbd Follow, 0xbe Continue on, 0xba and 0xbb Go there.
