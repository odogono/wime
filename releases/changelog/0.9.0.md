## [0.9.0] - 2026-10-21

### Added

- **The game now opens with the original's boot sequence.**
  The Melbourne House and Synergistic screens, the title screen with the
  Title music and the Credits, then the Ring verse lead into a new game,
  which opens with Gandalf's letter (#146).
- **Games are now kept in several named save slots.**
  The Archive window saves to a slot named Archive, and a game saved
  before this release is kept as that slot (#147).
- **The game now saves itself to an autosave slot.**
  It saves each game hour, on each change of Level and when the page is
  hidden, apart from the named slots (#148).
- **A title menu: Resume, New Game and Load.**
  After the boot sequence, a menu over the title screen resumes the most
  recent save, starts a new game (asking first when there is a save) or
  loads any save slot, by mouse or keys (#149).
- **An in-game menu: Save, Load, Return to title.**
  Escape or the Menu button opens it on every Level and pauses the game.
  Save into a new named slot or over one, load any slot, or autosave and
  go back to the title menu (#150).
