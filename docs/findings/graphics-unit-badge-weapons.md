**On the Campaign Level a Unit appears as a shield badge, and the weapon on the shield shows its Unit Type.**

| Unit Type      | Weapon       |
| -------------- | ------------ |
| Cavalry        | horse's head |
| Infantry       | sword        |
| Light infantry | spear        |
| Dwarf          | axe          |
| Elf            | bow          |
| Trolls         | club         |
| Orcs           | scimitar     |
| Corsairs       | scimitar     |

Most Units have a round shield. Elite Units, such as the Gondor Tower Guard, have a heraldic shield instead.
