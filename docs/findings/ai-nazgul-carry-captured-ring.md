**If the Nazgûl capture the Ring, by killing the Ring-bearer and all companions, they run for Barad-dûr or Orthanc and can be intercepted to win it back.**
The game is lost only when they reach Barad-dûr. The manual mentions Orthanc as a possible destination but does not say what happens if the Ring arrives there.
